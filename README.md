#  IPL Analytics

IPL Analytics is a web-based data analytics project that provides insights into Indian Premier League (IPL) matches, teams, players, and statistics.

##  Features

* IPL match statistics
* Player statistics
* Match and delivery data analysis
* Interactive visualizations
* User-friendly dashboard

##  Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Python
* Flask

### Data & Visualization

* Pandas
* Plotly
* IPL Dataset
* SQLite

##  Dataset

The project uses IPL match and ball-by-ball delivery data for analysis.

##  Purpose

The main purpose of this project is to analyze IPL data and present useful cricket insights through an interactive web application.
